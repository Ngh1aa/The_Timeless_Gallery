Visual Foundations

The visual system uses one font family — Inter — plus semantic route colors, a disciplined grid and a dark/light surface model that separates operational state from explanatory content.

Color system

Color is semantic first, expressive second.

The palette avoids neon fintech gradients. Cobalt identifies the selected route; green and muted red-brown communicate rail availability; navy carries operational state.
