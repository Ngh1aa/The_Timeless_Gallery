Responsive decisions

Mobile is a structural recomposition, not a scaled desktop.

Desktop structureMobile transformationReason
Hero copy beside route deskCopy first, route desk second.Context arrives before dense interactive content.
Spatial branch networkVertical rail-state stack.Preserve readable labels and touch-safe spacing.
Step list beside inspectorStep list followed by inspector.Sequence remains visible while the current state gets its own block.

Mobile fidelity

What is intentionally excluded.

Removed

—Brand imagery and logo asset
—Settlement atlas / halftone field
—Blue, green and orange semantic colors
—Final shadows, polish and animation

Preserved

✓Content hierarchy and section order
✓Scenario, route and mechanism interaction zones
✓Five-rail mental model
✓Evidence-before-conversion flow
Wireframe fidelity

Mobile wireframe uses only grayscale structural blocks and labels. It is meant for layout and UX evaluation before brand craft, imagery, color, motion or final component styling.
