# FinFlow Redesign Research Notes

## Goal
Create a memorable B2B FinTech campaign system that explains multi-rail settlement visually without inventing product claims.

## Pattern sources used
- 21st.dev — Animated Card Diagram, animated tabs, background paths and diagram-oriented marketing patterns.
- Flux UI — token-driven components, restrained spring/motion vocabulary and reduced-motion-aware implementation patterns.
- Animata — animated border/container, tab and card interaction patterns; MIT/open-source pattern reference.
- HuggingPT UI prompts — modern enterprise, analytics and minimal data-visualization visual directions.
- UIAI, Bmob prompt library and Kyla prompt library — prompt exploration references where accessible.

## Design decisions
1. Replace the previous "SaaS panel next to hero copy" with a network Control Plane that makes routing the signature object.
2. Use one high-contrast Signal Lime to indicate system state and conversion actions.
3. Keep the brief's five rails visible at once so the multi-rail proposition is never hidden behind tabs.
4. Use scenario tabs only to change the selected route, not to hide product structure.
5. Make the second section interactive so the education objective is solved through progressive inspection rather than six static cards.
6. Keep trust grounded in traceability and transparency rather than fabricated certifications or performance metrics.
7. Mirror the exact same control-plane motif in the 1:1 ad so the campaign has one recognizable visual system.

## Rejected patterns
- Glassmorphism-heavy cyberpunk styling.
- 3D token/globe imagery.
- Testimonial carousels without real customer evidence.
- Generic bento grids.
- Continuous ambient animations with no routing meaning.
